# 学習システム監査と改修の対応表

最終目標「英語論文を自力で読み、研究内容を英語で書ける」に向けた改修（2026-10）の記録です。

## 1. 既存システムの監査結果

| 領域 | 改修前の実態 | 問題点 |
|---|---|---|
| 解答記録 | すべての解答を `reviewItems` に1問1レコード（正答数・誤答数・連続正解・間隔）で保存 | 初回の正誤・日時が残らず、「初見で解けたか」「時間をあけても解けたか」を区別できない |
| 復習 | 正誤にかかわらず登録、間隔は最大30日、期限到来分を全件出題 | 復習が膨張（別途改修済み：1日5〜10問・30日超の間隔・持ち越し） |

対応：

- 解説が25字未満だった146問は、元の文を残したまま、文法的根拠・誤答の理由・応用を追記した。誤答理由がなかった選択問題には `whyOthersWrong` を追加した（`scripts/explanationPatches.ts`、適用は `npx tsx scripts/apply-explanation-patches.ts`）。
- 別の選択肢も文法的に正しかった2問（`grammar_l2_088` の is being、`grammar_l5_089` の show）は、その選択肢を明確な誤りに差し替えた。

## 3. Writing の採点範囲（オフライン）

入力式の解答（Writing の穴埋め・並べ替え・和文英訳・自由英作文、英文組み立て、研究英語の英作、Grammar の穴埋め・日本語→英語・誤文訂正・並べ替え、実力確認の英作文）は、次のように扱います。

| 状況 | 表示 | 記録上の扱い |
|---|---|---|
| 登録済みの解答と一致（大文字小文字・句読点・短縮形 don't = do not・数字表記 five = 5 の違いは無視） | 正解（自動判定） | 自動採点 |
| 一致しない | **要自己確認**：あなたの解答・模範解答・ほかに登録されている解答・文法確認項目・語の比較を表示し、「正しく書けていた／間違いがあった／判断できない」を選ぶ | 前の2つは自己評価として記録（自動採点と区別）。「判断できない」は正誤に数えず、翌日の復習で再確認 |
| 和文英訳・自由英作文・ノート課題 | アプリでは採点できないことを明示したうえで同じ確認画面 | 自己評価（実力確認では「参考値」として別欄） |

不一致をただちに不正解にはしません。別の表現でも正しい英文はあり得ますが、オフラインでは登録済みの解答との比較しかできないためです。選択式の問題は従来どおり自動採点です。

## 4. データの互換性と移行

- IndexedDB v4：`answerLog`（解答ログ）と `assessments`（実力確認）の2ストアを追加。既存レコードは書き換えていない。
- IndexedDB v5：`assessmentDrafts`（途中の実力確認）を追加。`reviewItems` と `answerLog` で旧表記のタグ（`There is/are`）を内部ID（`there-is-are`）に置き換えた。変更したのはタグ欄だけで、正誤数・間隔・日時は変えていない。
- 文法タグは内部ID（集計・復習・ドリル・Theory の対応に使う）と表示名（`src/data/grammar/tagLabels.ts`）を分けた。旧表記は読み込み時にも内部IDに変換するので、古いバックアップを読み込んでも弱点集計が分かれない。
- `ReviewItem` に追加した項目（`inReview` / `firstAnswerCorrect` / `delayedAttempts` / `pendingSelfCheck` など）はすべて任意。古いレコードは読み込み時に解答履歴から判定する。
- 改修前の解答は「初回の正誤」「遅延復習」が記録されていないため、それらは改修後の解答から集計する（それまでは「未確認」）。
- バックアップ（設定 → Export）は形式 v5 で、途中の実力確認も含む。v1〜v4 のバックアップもそのまま読み込める。
- テスト：v3 のデータベースを現行版に上げても全レコードが残り、タグだけが置き換わること。旧バックアップを読み込めること（`tests/dbMigration.test.ts`、`tests/accuracyAndResume.test.ts`）。

## 5. 習熟度の表示

| 表示 | 条件 | 復習との関係 |

| 学習済み | 1回以上解答し、直近は不正解でない。改修前の記録もすべてここに含まれる | 通常の間隔で出題 |

| 未学習 | 保存しただけで、まだ解答していない | — |

## 6. 4週間ごとの実力確認の中断・再開

- 開始時に、問題とそれぞれが初見かどうかを確定して保存する。1問答えるたびに保存するので、アプリやブラウザを閉じても続きから再開できる。
- 一度確定した解答（選択した後や、自己確認で選んだ後）は、再開後も変更できない。
- 最後まで答えるまでは、成績・復習・解答ログ・実力プロファイルのどれにも反映しない。終了時にまとめて反映する。終了処理が途中で止まった場合も、反映済みの解答は二重に数えない。
- 「破棄して最初からやり直す」を選ぶと、途中の回答は反映されずに削除される（確認ダイアログあり）。

## 7. 実力確認の難易度管理

各問題のメタデータは、既存の項目をそのまま使い、推定難易度だけを計算で付けます（`src/services/questionMetadata.ts`。問題データは複製しません）。

| 項目 | 内容 | 出どころ |
|---|---|---|
| 学習項目・文法タグ | 文法タグ（内部ID）、語彙カテゴリ、読解の設問タイプ | 既存の `tag` / `category` / `skillTag`（読解の約8割は skillTag がないため設問文から判定） |
| 問題形式・測定する能力 | 4択・正誤・文全体の比較・英作など／文法・語彙・読解・構文理解・英作文 | 既存の `format` と実力確認のセクション |
| 推定難易度（基礎・標準・応用） | 下記の負荷スコアを、同じ Level・同じ種類の問題の中で3段階に分けたもの | 計算（暫定） |
| 初見・既習 | 学習者がその問題に答えたことがあるか（重複問題は1つとして扱う） | 解答記録。実力確認の開始時に確定 |

**推定難易度の決め方（暫定評価）**：Level では決めず、問題そのものから「負荷スコア」を計算し、根拠を記録します。

- 必要な知識：文法項目・語の種類（基本・標準・発展）
- 解答過程：正誤判断／4択／文全体の比較／形を自分で書く／文構造の分析／誤文訂正・英作
- 答えの手がかり：yesterday・since・than などの手がかり語があるか、選択肢が同じ語の変化形か意味の違う語か、読解の正解が本文の言い換えか、誤答に本文の語が使われているか
- 処理する量：文・本文・選択肢の長さ、空欄の数、複数語の答え、否定形の設問

同じ Level・同じ種類の問題の中で負荷スコアを3等分に近く分けます。同じスコアの問題が別の帯に分かれることはなく、問題の種類が偏っている場合は帯の大きさが偏ります（例：Level 1・2 の読解は単純な内容一致問題が多い）。この推定は解答データ（項目反応理論など）で検証したものではなく、画面にも「暫定値」と表示します。分布は `npx tsx scripts/report-difficulty.ts --samples` で確認できます。

**出題構成**：毎回同じ構成比で出題します（文法 基礎2・標準2・応用2、語彙 2・2・2、読解 1・2・1、構文理解 1・1・1、短い英作文 標準1・応用1）。各帯では初見の問題を優先し、文法タグと問題形式を分散させます。初見が足りない帯は既習の問題で補い、帯そのものが足りない場合は隣の帯で代替します。どちらの場合も「今回の出題構成について」として結果に記録します。語彙は毎回同じ形式（英→日の意味選択）で出題します。

**比較**：前回の結果と比べるときは、Level・推定方式・問題数・推定難易度の構成（1問分の違いまで）・初見の数がそろっている場合だけ「前回比」と表示します。そろっていない場合は「参考（比較精度は限定的）」として理由を表示します。構成の記録がない以前の結果との比較も参考値です。自己評価の自由英作文は比較しません。

## 9. 重複問題

`grammar_l2_043` と `grammar_l2_155` は、問題文・選択肢（順序のみ違う）・正答・タグ・レッスンが同じ完全な重複でした。同じ確認で見つかった次の4組も同じ知識を問う重複です：l2_126 / l2_197（完全一致）、l2_120 / l2_158（解説の表現のみ違う）、l3_004 / l3_111（l3_111 は英語として成り立たない選択肢を含む）、l5_004 / l5_083（l5_083 は選択肢 was も正しい）。

各組の後者を新しい出題（毎日のトレーニング・追加トレーニング・実力確認・類題）の対象から外しました（`src/data/grammar/duplicates.ts`）。問題データと学習履歴は残し、復習では引き続き出題できます。2つは同じ知識として扱うので、同じ日の復習で両方が出ることはなく、片方に答えていればもう片方も「既習」になります。毎日のトレーニングで除外された問題が当たる日は、その日の文法問題が1問少なくなります（他の日の出題は変わりません）。

## 10. 自己評価と客観的な正答率の区別

自動判定と自己評価の併用はそのままです。次の数値は、アプリが判定した解答だけで計算し、自己評価は含めません：実力プロファイルの既習・初見・遅延復習、弱点分析の正答率、Grammar／Review の累計正答率、今日の復習の正解数、週間ミッションの初見正答率、実力確認の各セクション（自己評価の英作文は「参考」として別欄で、前回比較もしません）。

項目ごとに自己評価の回数を別に記録し（`selfGraded`）、それ以前の記録は解答ログ（v4 以降の全解答に判定方法を記録）から区別します。和文英訳・自由英作文・ノート課題は常に自己評価なので、客観的な正答率から除外します。

## 11. 残っている課題

- 推定難易度は規則による暫定評価で、解答データによる検証（難易度・識別力の推定）はしていない。十分な解答データがたまった段階で見直す必要がある。
- 問題の種類が偏っているプール（Level 1・2 の読解など）では、目標の構成比を毎回は満たせない。その場合は結果に記録し、比較は参考値になる。
- 自動判定は登録済みの解答との一致に限られる。登録外の正しい表現は、学習者の自己評価に頼る。
- 読解の内容一致問題の解説は本文の引用が中心で、誤答の理由は個別には書いていない。
- 解答ログがない v3 以前の記録のうち、復習の自己評価カード（出典のない保存単語など）で答えたものは、自己評価として区別できない（数は少ない）。
- `l2_167` と `l3_016` は別 Level に同じ問題文がある（Level が違うため除外していない）。
